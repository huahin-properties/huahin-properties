# Handoff Checklist

## ก่อนส่งมอบ
- ☐ `../../BLUEPRINT.md` อัปเดตล่าสุด ไม่มี conflict ค้าง
- ☐ `../../Mission Control.dc.html` อัปเดตสถานะล่าสุด
- ☐ `CURRENT_PHASE_STATUS.md` ตรงกับความเป็นจริง
- ☐ `../../PROJECT_HISTORY.md` บันทึกครบทุกงานที่ปิดแล้ว
- ☐ `KNOWN_ISSUES.md` ตรงกับบั๊ก/ข้อจำกัดล่าสุด
- ☐ `../../RELEASE CHECKLIST.md` ผ่านครบ (ถ้ามี release ค้าง)
- ☐ Next Action ชัดเจน ไม่มีความกำกวม
- ☐ ผู้รับผิดชอบขั้นตอนถัดไประบุชัดเจน (CEO / Claude / Product Owner)

## สิ่งที่ต้องส่งให้ผู้ช่วยใหม่
- ☐ `CEO_ASSISTANT_START_HERE.md`
- ☐ `PROJECT_CONTEXT_SNAPSHOT.md`
- ☐ `CURRENT_PHASE_STATUS.md`
- ☐ `PROJECT_OPERATING_STANDARD.md`
- ☐ `../../PROJECT_HISTORY.md`
- ☐ `KNOWN_ISSUES.md`
- ☐ `../../RELEASE CHECKLIST.md`

## สิ่งที่ผู้ช่วยใหม่ต้องยืนยันก่อนเริ่มงาน
- ☐ อ่านเอกสารครบตามลำดับใน `CEO_ASSISTANT_START_HERE.md`
- ☐ เข้าใจ Current Phase (`CURRENT_PHASE_STATUS.md`)
- ☐ เข้าใจ Scope ของงานที่กำลังจะทำ
- ☐ เข้าใจ Known Issues ที่ค้างอยู่
- ☐ เข้าใจ Next Action และผู้รับผิดชอบ
- ☐ ไม่อ้างอิงข้อมูลเก่าที่ขัดแย้งกับเอกสารชุดนี้
- ☐ พร้อมทำงานต่อโดยไม่ต้องถามซ้ำสิ่งที่มีอยู่แล้วในเอกสาร
