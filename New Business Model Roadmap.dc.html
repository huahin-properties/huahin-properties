huahin . properties — New Business Model Roadmap
บันทึกทิศทางธุรกิจใหม่: Central Inventory + Buyer Matching + Viewing History — ระบบเดิม (Agent Membership/Mini-Site) เก็บรักษาไว้ ไม่ลบ ไม่รื้อ
ลำดับการพัฒนา 3 ฝั่ง
1. ฝั่งเจ้าของ/ผู้ฝากขาย-เช่า (Owner) — ทำก่อน เพื่อให้มีทรัพย์เข้า Central Inventory
2. ฝั่งผู้ซื้อ (Buyer) — ทำต่อ ใช้ทรัพย์จริงจากขั้น 1 ทดสอบค้นหา/AI Matching/สร้าง Lead
3. ฝั่ง Sales/Viewing Agent ภายใน — ทำท้ายสุด ใช้ Lead จริงจากขั้น 2 ทดสอบมอบหมาย/นัด Viewing/บันทึกผล
แต่ละฝั่งทำแยกกันได้ ไม่ต้องพร้อมกัน — ตามหลัก Simple First
ฝั่งที่ 1 — เจ้าของ/ผู้ฝากขาย-เช่า (ต้นน้ำ → ปลายน้ำ)
9 ขั้นตอน รวมทุกฟังก์ชันที่ตกลงกันไว้
1
จุดเข้า — คลิกเมนู "ฝากขาย/เช่า" หรือพิมพ์ในแชท AI ว่าอยากฝากขาย → ระบบตรวจจับคำ แสดงปุ่มลิงก์ไปหน้ากรอกข้อมูล
2
ระบุตัวตนแบบเบา — ชื่อ + เบอร์โทร/อีเมล (หรือ login ด้วย Google/LINE เพื่อติดตามสถานะย้อนหลัง) → ระบบตรวจสอบเบอร์โทรซ้ำกับทรัพย์ที่เคยฝากไว้ก่อนหน้า (เตือน Admin ถ้าซ้ำ ไม่บล็อกอัตโนมัติ) → ถ้าเจ้าของมีทรัพย์อื่นฝากไว้แล้ว ดึงข้อมูลติดต่อเดิมมาเติมให้อัตโนมัติ ไม่ต้องกรอกซ้ำ
3
เลือกประเภทธุรกรรม — ขายหรือเช่า (status: sale/rent)
4
กรอกข้อมูลทรัพย์ — ประเภททรัพย์ (type) → สภาพทรัพย์ (condition: มือ1/มือสอง) → ราคา → รายละเอียด → อัปโหลดรูปขั้นต่ำตามเกณฑ์ที่กำหนด (เช่น 5 รูปขึ้นไป) → ปักหมุดตำแหน่งจริง → ข้อมูลติดต่อเจ้าของจริง → แนบเอกสารยืนยันความเป็นเจ้าของ (ไม่บังคับ แต่แนะนำ — โฉนด/สัญญาเดิม) → ระบบบันทึก source: owner_submission อัตโนมัติ
5
Admin กำหนดค่าคอมมิชชั่น/ระดับบริการ — Admin/ทีม Sales คุยตกลงกับเจ้าของ แล้วเลือก/กรอกอัตราเข้าระบบ (มาตรฐาน 3% / เร่งขาย 5% / Exclusive 10%, override ได้ทุกกรณี)
6
ยอมรับสัญญาฝากขาย/ฝากเช่า — สัญญาดึงอัตราจากข้อ 5 มาแสดงอัตโนมัติ พร้อม: ระยะเวลาฝาก, สิทธิ์ถอนประกาศเองได้จากหน้าติดตามสถานะเมื่อใดก็ได้, ยืนยันสิทธิ์ความเป็นเจ้าของจริง, ข้อมูลเผยแพร่สาธารณะ VS เก็บภายใน — บันทึกวันเวลา+เวอร์ชันที่ยอมรับไว้เป็นหลักฐาน
7
ส่งตรวจสอบ — กดส่ง → สถานะ "รอตรวจสอบ" เจ้าของติดตามผ่านลิงก์ส่วนตัว (เบอร์โทร/อีเมล) ที่ให้ถอนประกาศเองได้ด้วย → ระบบยิงแจ้งเตือนเข้า LINE ทีมงาน/Admin ทันที (ชื่อทรัพย์/ราคา/เบอร์เจ้าของ + ลิงก์ตรวจสอบ เข้าถึงจากมือถือได้)
8
Admin ตรวจสอบข้อมูล — ผ่านหน้า Listing Approvals ที่กรองซ้อนได้หลายมิติ (ขาย/เช่า × ประเภท × มือ1-มือสอง × ที่มา) รองรับมือถือ → ถ้าไม่ครบ กด "ขอข้อมูลเพิ่ม" → ระบบแจ้งเตือนกลับเจ้าของอัตโนมัติทุกครั้งที่สถานะเปลี่ยน (SMS/LINE/อีเมล) → ถ้าเจ้าของไม่ตอบกลับภายใน 7-14 วัน ระบบปิดเคสอัตโนมัติ (auto-expire)
9
อนุมัติและเผยแพร่ — Admin กด Approve → เข้า Central Inventory (จัดเก็บแยกประเภทครบตามข้อ 4) → เผยแพร่ Public (ตำแหน่งโดยประมาณเท่านั้น) → แจ้งผลเจ้าของอัตโนมัติ พร้อมช่องทางติดตาม Lead ผ่านทีมงานเรา → ทรัพย์ที่ขาย/เช่าสำเร็จหรือค้างนานเกินกำหนด ระบบแจ้งเตือน Admin ให้ปิด/ต่ออายุประกาศ
ยังไม่ได้ลง Step-by-Step (รอทำต่อตามลำดับ)
ฝั่งที่ 2 — ผู้ซื้อ (Buyer): ค้นหา/คุยกับ AI → Matching % → Lead → Screening → มอบหมาย Sales/Viewing Agent → นัด Viewing → Feedback/History → Follow-up → Negotiation → Closing
ฝั่งที่ 3 — Sales/Viewing Agent ภายใน: รับมอบหมาย Lead → เข้าถึงข้อมูลทรัพย์/เจ้าของ → บันทึกผล Viewing → Commission-split ภายในทีม (ถ้ามี)
กฎสำคัญ: ห้าม Delete / ห้ามรื้อระบบเดิม (Agent Membership, Mini-Site, Package, Social Share) — ถือเป็น Existing/Reserved System
