# แผง PROJECT-STATUS ภายใน (Claude Code)

**เปิดดู:** ดาวน์โหลด/เปิดไฟล์ `docs/status-panel/index.html` ในเบราว์เซอร์ (ไฟล์เดียว ไม่ต้องต่อเน็ต; ฟอนต์จะใช้ฟอนต์ระบบถ้าโหลดฟอนต์ไม่ได้). บน GitHub: เปิดไฟล์ → Download raw file → ดับเบิลคลิก. ตัวอย่างหน้าจอ: `shots/`.

**แหล่งข้อมูลเดียว:** `PROJECT-STATUS.md` — ตาราง §1–§3 (Roadmap 0–24, ฐาน C0–C4.2, งานปัจจุบัน) และบล็อก `STATUS-REGISTRY` §6 (ผู้รับผิดชอบ, checklist ร่างสำหรับเปอร์เซ็นต์, ทะเบียนค้าง, ประวัติ). **ห้ามแก้ `index.html` ด้วยมือ** — แก้ PROJECT-STATUS.md แล้ว:
```
npm run status-panel         # สร้าง docs/status-panel/index.html ใหม่ (ตรวจ registry ก่อน ถ้าผิดจะไม่เขียนไฟล์)
npm run test:status-panel    # ตัวเลขใน HTML ต้องตรงทะเบียน; เปิดจริงในเบราว์เซอร์ที่จอใหญ่และมือถือ
node tools/status-panel/build.js --check   # ตรวจ registry อย่างเดียว
```
**เปอร์เซ็นต์:** ผ่าน ÷ รายการที่ใช้ได้ ของขอบเขตเดียว ระดับหลักฐานเดียว แสดงต่อเมื่อ checklist ถูก Work lock (`locked:true`); ตอนนี้ทุกชุดเป็นร่าง จึงแสดง "ยังคำนวณไม่ได้" พร้อมตัวอย่างที่ระบุว่าไม่ใช่ความคืบหน้า. ไม่มีเปอร์เซ็นต์รวมทั้งโครงการ.
**ความสด:** แผงแสดง commit ที่ build และไม่ตรวจความสดอัตโนมัติ. **ห้ามใส่** รหัสผ่าน คีย์ อีเมล เบอร์ หรือ token (validator ปฏิเสธ).
